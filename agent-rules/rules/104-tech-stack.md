## Rules

- **104.1** One package manager: `yarn`. Install with `yarn install --frozen-lockfile` in each
  package; only `yarn.lock` is updated. The `package-lock.json` files are not touched (Q-02).
- **104.2** Node.js major version is 22 (`NODE_MAJOR` in `agent-rules/project.sh`).
- **104.3** New dependencies are pinned to a version range the lock file resolves (never `latest` or
  `*`). Dependencies already declared as `latest`: none.
- **104.4** Environment files: committed, without secrets: `functions/.env.test-project` (synthetic
  values for the test emulator), `twa/.env.development` (fake bot token for the dev sign-in and how to set up the browser
  Telegram login, read by `next dev` only) and `twa/.env.production` (public values of the production build).
  Not committed: `functions/.env` (T-Bank terminal credentials, DeepSeek API key) and
  `functions/.env.local` (a real bot token for testing the browser Telegram login) and
  `twa/.env.development.local` (emulator URL or `DEV_API_PROXY` / `DEV_TUNNEL_HOST` for `next dev`; a `.env.local` would also be read by
  production builds) (rule 110.2).
- **104.5** API types: generated by `yarn openapi` in each package from its contract
  (`functions/resources/openapi/*.yml` → `functions/src/openapi/`, `crm/openapi/api.yml` →
  `crm/src/api/openapi/crm.d.ts`, `twa/openapi/*.yml` → `twa/src/api/openapi/`,
  `bot/resources/openapi/api.yml` → `bot/src/openapi/crm.d.ts`); the output is committed (rule 108).
- **104.6** Backend (rule 106): source in `functions/src`, contract
  `functions/resources/openapi/api.yml` and `models.yml`; no root `dev` script yet (rule 201.5);
  the functions emulator starts with `cd functions && yarn serve`; integration tests run with
  `firebase emulators:exec --project test-project --only firestore,functions 'yarn test'` from
  `functions/`.
