# Source tasks

Original task texts from the task tracker. Each file `<id>.md` is copied verbatim and never edited;
a new version of a task text is added below the old one with its date. Acceptance criteria derived
from a task are labelled `[<TRK>-<id>]` (prefix from `project.tracker.label`) in
`../../features/FEATURE_REGISTRY.yaml`, and the task lists the id in `tracker_ids`.
